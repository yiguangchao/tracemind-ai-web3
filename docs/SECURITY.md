# 安全边界

Tracemind AI Web3 是一个只读交易解释工具，核心目标是帮助用户理解测试网交易和合约交互记录。

## 本项目不会做的事

- 不读取、保存或上传私钥。
- 不读取、保存或上传助记词。
- 不自动签名。
- 不自动转账。
- 不自动 approve 授权。
- 不托管钱包资产。
- 不把 OpenAI API Key 暴露到前端。

## 用户需要人工确认的事

- 确认交易发生在预期网络。
- 确认 from 地址和 to 地址符合预期。
- 确认是否涉及 ETH 或 Token 转账。
- 确认是否涉及 approve、transferFrom 等高风险操作。
- 在区块浏览器中核对交易哈希和状态。

## AI 输出边界

AI 解释仅用于学习参考，不构成投资建议、安全审计结论或操作指令。  
当链上 input data 无法解码时，AI 必须承认不确定性，不能编造合约名称、项目名称或交易目的。
